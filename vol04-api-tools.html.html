00

APIとは何か

難しそうに聞こえますが、仕組みはとてもシンプルです。レストランの注文カウンターで全部わかります。

CONCEPT

API

Application Programming Interface（アプリケーション・プログラミング・インターフェース）

アプリ（お客さん）がAPI（注文カウンター）に注文を出すと、サービス側（厨房）がデータや処理結果を返してくれる

レストランを想像してください。お客さんは「カルボナーラをください」と注文します。でも厨房に直接入って料理を作ることはできません。注文カウンターを通して頼むだけです。

APIはまさにこの「注文カウンター」です。アプリ（お客さん）がAPI（カウンター）に「このデータをちょうだい」「この操作をして」と頼むと、サービス側（厨房）が処理して結果を返してくれます。お客さんは厨房の中身（サーバーの構造・データベースの設計）を知らなくていいのです。

AIとの関係で言えば、Claude CodeはAPIを通じて各サービスと通信します。APIの仕様（ルール）さえ守れば、AIが自動でデータ取得・操作・送信ができるようになります。このページで紹介する18ツールは、すべてAPIを持っているため、Claude Codeや自動化ツールから操作可能です。

01

コミュニケーション

ビジネスチャット・コミュニティ系のツール。通知・レポート配信・メッセージ管理の自動化に特に活用される。

3 TOOLS
💬
Slack
Salesforce, Inc.

ビジネスチャットの代名詞。通知・レポート・問い合わせ対応の自動化に最もよく使われるAPIのひとつ。

チャンネル・DM・スレッドなど多彩なコミュニケーション形式に対応し、世界中の企業で使われているビジネスチャットツール。APIで業務自動化との相性が非常に高く、「特定のイベントが起きたらSlackに通知する」「毎朝集計レポートをチャンネルに投稿する」という用途で頻繁に活用される。Webhookを使えばコーディングなしでも外部サービスからメッセージを送れる。

① 指定チャンネルへの自動メッセージ送信（障害通知・日次レポートの自動配信）／② 過去メッセージの検索・取得（議事録の自動生成・情報収集の効率化）／③ ユーザー一覧・在席状況の取得（勤怠管理・ワークフロー自動化への活用）
🎮
Discord
Discord Inc.

ゲーマー発祥のコミュニティプラットフォーム。ボット連携が充実しており、コミュニティ運営の自動化に強い。

もともとゲーマー向けに開発されたが、現在はビジネス・クリエイター・Web3コミュニティでも広く活用される。ボット（Bot）連携が豊富で、自動化の自由度が高いのが特徴。イベント告知・FAQ自動応答・新メンバーへのウェルカムメッセージなど、コミュニティ運営の多くを自動化できる。

① サーバー内への自動通知・お知らせ投稿（イベント告知・更新情報の配信）／② チャンネル一覧・メッセージ履歴の取得（コミュニティの活性度分析）／③ ロール付与・剥奪（特定条件を満たしたメンバーへの自動権限管理）
👥
Microsoft Teams
Microsoft Corporation

Microsoft 365と深く統合されたビジネスツール。大企業・官公庁での採用が多く、Graph APIで広範な操作が可能。

会議・チャット・ファイル共有を一元管理でき、OutlookやSharePointとも連携できる「Graph API」が特徴。大企業・官公庁での導入率が高く、社内システム統合の基盤として活用されることが多い。AIコンサルが企業向け提案をする際に、最もよく出てくるコミュニケーション基盤のひとつ。

① チャンネルへのメッセージ送信（社内報・アラートの自動配信）／② 会議スケジュールの作成・変更・参加者への通知自動化／③ チームメンバー一覧・組織情報の取得（人事連携・ディレクトリ管理の自動化）
02

ドキュメント・ストレージ

ファイル管理・文書作成系のツール。バックアップ自動化・レポート保存・資料配布フローの構築に活用される。

3 TOOLS
📂
Google Drive
Google LLC

Googleのクラウドストレージ。Docs・Sheets・Slidesと連携が強力で、普及率が高いため自動化の出発点になりやすい。

Docs・Sheets・Slidesとのシームレスな連携が強力で、リアルタイム共同編集が可能。15GBまで無料のため個人・法人問わず普及率が高く、業務ドキュメントの保存・共有基盤として最も広く使われているクラウドストレージ。Claudeとの連携（Connector）も標準対応しており、「このフォルダの資料を全部読んで要約して」という作業が自然言語でできる。

① 指定フォルダへのファイル自動アップロード・整理（定期バックアップの自動化）／② ファイル名・更新日・共有状況のリスト取得（棚卸し・監査への活用）／③ 共有権限の変更・リンク発行（承認フロー・配布の自動化）
📦
Dropbox
Dropbox, Inc.

ファイル同期・共有に特化したクラウドストレージの先駆け。クリエイターの納品物管理フローに特に活用されやすい。

デバイス間の自動同期が強力で、クリエイター・デザイナー間の大容量ファイルのやりとりに多用される。Paperという文書作成機能も内包しており、単なるストレージを超えたコラボレーション基盤として機能する。クライアントへの納品物管理・資料配布フローの完全自動化に適している。

① ファイルのアップロード・ダウンロード（納品物の自動受け渡しフローの構築）／② 共有リンクの発行・有効期限設定（クライアントへの安全・確実な送付）／③ フォルダ構成の取得・新規作成（プロジェクト開始時の自動セットアップ）
📝
Notion
Notion Labs, Inc.

メモ・Wiki・DB・タスクを統合したワークスペース。AIコンサルの情報基盤として、顧客管理・議事録・ナレッジ蓄積に最適。

メモ・Wiki・データベース・タスク管理を1つに統合したオールインワンワークスペース。スタートアップから大企業まで幅広く導入され、日本語対応も充実。Claudeとの連携（Connector・MCP両対応）が特に強力で、「今日の打ち合わせ内容をNotionの議事録データベースに追加して」という指示一つで自動保存できる。HUMMERさんが現在セットアップ中のAIコンサル業務の情報基盤としても最適。

① データベースへのレコード追加・更新（顧客情報・案件管理の自動入力）／② ページの新規作成・本文更新（議事録・レポートの自動生成・保存）／③ データベース検索・フィルタリング（特定条件のタスクや情報の一括取得）
03

開発・DevOps

コード管理・CI/CD系のツール。Issue管理・自動デプロイ・コードレビューの自動化に活用される。

3 TOOLS
🐙
GitHub
GitHub, Inc. (Microsoft)

世界最大のソースコード管理プラットフォーム。Claude CodeとGitHub Pages・Actionsを組み合わせると、AIコンサルの公開基盤になる。

GitリポジトリのホスティングはもちろんCI/CD・Actions・Pages・Copilotまでカバーする開発者必須のハブ。Claude CodeとGitHub MCPを組み合わせると、コード生成からIssue作成・PRレビュー依頼・リリースノート作成まで自律的に実行できる。HUMMERさんのAIコンサル成果物公開（hummer-lab-001.github.io）にも直結する重要ツール。

① Issue・Pull Requestの自動作成・ステータス更新（開発フロー管理の自動化）／② リポジトリ内ファイルの読み取り・新規コミット（AIが直接コードを反映）／③ リリース・タグの作成・変更履歴の自動生成（リリース作業の完全自動化）
🦊
GitLab
GitLab Inc.

セルフホスティング可能なDev(Sec)Opsプラットフォーム。セキュリティ要件が厳しい大企業・官公庁への提案で必ず名前が出る。

GitHubと双璧をなすプラットフォームで、自社サーバーで動かせる（セルフホスティング）ため、セキュリティ要件が厳しい金融機関・官公庁・大企業に採用されやすい。CI/CDパイプラインの機能が特に充実しており、開発・テスト・デプロイの自動化に強みを持つ。

① プロジェクト・Issue・Merge Requestの一覧取得・作成・更新（開発進捗管理）／② CI/CDパイプラインのトリガー実行・実行状況の監視（ビルド自動化）／③ コミット差分の取得・コードレビューコメントの自動生成
⚙️
CircleCI
Circle Internet Services, Inc.

クラウドネイティブなCI/CDサービス。コードをpushするたびに自動でテスト・ビルド・デプロイを実行する「継続的インテグレーション」の代表格。

設定ファイル1つで複雑なパイプラインを構築でき、テスト自動化・品質管理に強い。「コードを書いたら自動でテストして、問題なければ本番反映」という流れをAPIで制御できる。スタートアップ〜中堅企業でのCI/CD基盤として広く採用されている。

① パイプラインのトリガー実行（特定ブランチのビルド・テストを任意のタイミングで起動）／② ジョブ・ワークフローの実行状況取得（ビルド成否の監視・Slack通知連携）／③ 環境変数の取得・更新（デプロイ設定の動的変更・シークレット管理）
04

データ・データベース

データ管理・分析系のツール。集計・レポート生成・データ操作の自動化に活用される。

3 TOOLS
📊
Airtable
Formagrid, Inc.

スプレッドシートとDBを融合させたノーコードツール。非エンジニアでも本格的なデータ管理ができ、中小企業の業務基盤として人気。

フォーム・ギャラリー・カンバン・タイムラインなど多彩なビューを持ち、非エンジニアでも本格的なデータ管理が可能。顧客管理・在庫管理・業務管理など幅広い用途に対応。SMB（中小企業）向けAI導入提案において、Notionと並んで最もよく登場するデータ基盤。

① レコードの一括取得・フィルタリング（条件付き顧客リストや案件一覧の自動抽出）／② 新規レコードの追加・既存レコードの更新（フォーム入力内容の自動登録）／③ テーブル構造の取得（ダイナミックなフォーム・帳票の自動生成）
🍃
MongoDB
MongoDB, Inc.

JSONに近い「ドキュメント型」データベース。スキーマが柔軟なためスタートアップや変化の速いサービスに多用される。

データをJSONに近い形式で柔軟に保存できるため、仕様が頻繁に変わるスタートアップのプロダクト開発に多用される。Atlas Data APIを使えばサーバーレスで外部からDBを直接操作でき、バックエンド開発を大幅に簡略化できる。AIコンサルがSaaSプロダクト開発を支援する際によく出てくるDB選択肢。

① コレクション内のドキュメント検索・条件絞り込み（ユーザー情報・ログの取得）／② 新規ドキュメントの挿入・既存データの更新・削除（CRUD操作の自動化）／③ 集計パイプラインの実行（月次売上集計・ユーザー行動分析の自動化）
📈
Google BigQuery
Google LLC

Googleのサーバーレス大規模データウェアハウス。数TB〜PBのデータにSQLを実行でき、マーケ分析・BI連携の基盤として急増中。

数TB〜PBのデータにSQLを実行でき、処理速度が圧倒的なサーバーレス型のデータウェアハウス。Google Analytics・Google広告データとの連携が特に強力で、マーケティング分析のデータ基盤として採用企業が急増している。AIコンサルがデータ活用提案をする際に、避けては通れないプラットフォーム。

① SQLクエリの実行・結果取得（大規模データの自動集計・週次レポートの自動生成）／② データセット・テーブルの一覧取得・スキーマ確認（データカタログの自動化）／③ テーブルへのデータ挿入（外部システムからのストリーミングデータ投入）
05

マーケティング・CRM

顧客管理・メール配信系のツール。リード管理・商談追跡・メールマーケティングの自動化に活用される。

3 TOOLS
🧡
HubSpot
HubSpot, Inc.

マーケ・営業・CSを一体化したオールインワンCRM。中小企業から大企業まで世界20万社以上が採用しており、日本でも急速に普及中。

メール配信・LP作成・パイプライン管理・カスタマーサポートまでカバーする統合型CRM。無料プランが充実しており、スタートアップが最初に導入するCRMとしても人気。AIコンサルが中小企業へのCRM導入を提案する際に、最も推奨しやすい選択肢のひとつ。

① コンタクト（顧客）の新規登録・プロパティ更新（フォーム→CRM自動連携）／② Deal（商談）の作成・ステージ変更（営業パイプライン進捗の自動管理）／③ マーケティングメールの送信・開封率・クリック率などの効果測定データ取得
☁️
Salesforce
Salesforce, Inc.

世界シェアNo.1のCRMプラットフォーム。大企業・士業・コンサル業界での採用率が高く、顧客管理基盤の定番。

リード管理・商談・契約・サポートまで営業プロセス全体をカバー。大企業での採用率が高く、士業・コンサル業界でも顧客管理基盤として普及しており、AIコンサルの対企業向け提案で必ず名前が出るプラットフォーム。豊富なカスタマイズ性と豊富なAPIが特徴。

① 取引先・リード・商談のSOQL検索・作成・更新（営業データ管理の自動化）／② レポートデータの取得（KPIダッシュボードへの自動データ反映）／③ Apexトリガー・フロー連携による承認フロー・通知プロセスの自動化
🐒
Mailchimp
Intuit Inc.

世界最大級のメールマーケティングプラットフォーム。無料プランが充実しており、スタートアップ・個人事業主にも人気が高い。

キャンペーン作成から配信・効果測定まで一貫管理できるメールマーケティングの定番ツール。ニュースレター・セール告知・顧客育成メールに幅広く活用され、AffiliateHub/NEWXUSのようなアフィリエイト基盤との組み合わせでも効果を発揮する。

① メーリングリストへの会員追加・削除・タグ付け（セグメント管理の完全自動化）／② キャンペーンの作成・スケジュール設定・送信（メール配信フローの自動化）／③ 開封率・クリック率・購読解除数などの詳細レポートデータ取得
06

その他・ユーティリティ

AI・決済・自動化系のツール。AIプロダクト開発・サービス販売・業務連携に幅広く活用される。

3 TOOLS
🤖
OpenAI
OpenAI, L.L.C.

ChatGPTやGPT-4を提供するAI企業。APIを通じて多様なAI機能を自社サービスに組み込める業界標準のAI API。

テキスト生成・画像生成・音声認識・埋め込み（Embedding）など多様なAI機能を提供。AI機能の外部組み込みにおける業界標準として、多くのSaaSやアプリに内蔵されている。ClaudeのAPIと並んで、AIコンサルが最も頻繁に提案する外部AI API。

① テキスト生成・チャット応答（カスタムAIアシスタント・自動返信ボットの構築）／② DALL-E APIによる画像生成（テキストプロンプトからビジュアルを自動作成）／③ Embeddingによるテキストのベクトル化（類似検索・RAG構築の基盤）
💳
Stripe
Stripe, Inc.

開発者フレンドリーなオンライン決済プラットフォーム。AIコンサルのサービス販売・サブスクリプション管理の基盤として最もよく使われる。

クレジットカード・銀行振込・定期課金・マーケットプレイス決済など幅広い決済形式に対応。APIのドキュメントが充実しており、エンジニアに最も選ばれている決済プラットフォーム。AIコンサルのサービス販売・BOOTHでの商品販売・サブスクリプション管理の基盤として直接活用できる。

① 決済リンク・請求書の自動発行（受注後の請求処理を完全自動化）／② サブスクリプションの作成・プラン変更・解約処理（定期課金の管理）／③ 入金状況・売上レポートの取得（経理・財務レポートの自動生成）
⚡
IFTTT
IFTTT Inc. ／ If This Then That

「もしAが起きたらBをする」を自動化するプラットフォーム。プログラミング不要で700以上のサービスをつなげる入門向け自動化ツール。

異なるWebサービスを「トリガー→アクション」の形でつなぐ自動化プラットフォーム。プログラミング不要で700以上のサービスを連携でき、業務自動化の入門として最適。非エンジニアのクライアントに「まず試してみましょう」と提案しやすい自動化ツールの代表格。

① Webhookトリガーの発火（外部システムからIFTTTアプレットを任意に起動）／② アプレット（自動化レシピ）の有効化・無効化（シナリオの動的切り替え）／③ サービス連携状況・実行履歴の取得（自動化の監視・エラー検知）

AI機能の組み込み
既存サービスにClaude/OpenAI APIを加えて、文章生成・分析・翻訳機能を追加する。

APIを知ると、自動化の設計図が描けるようになる

「このツールにAPIがある」と知っているだけで、業務改善の発想が大きく変わります。

「Notionにデータが入ったら→Slackに通知→Stripeで請求を発行」という一連の流れも、それぞれのAPIをつなぐことで実現できます。Claude CodeはこうしたAPIを代わりに呼び出してくれる存在です。

次のVol.05では、APIをさらに進化させた「MCP（Model Context Protocol）」対応ツールを紹介します。APIとMCPの決定的な違いも、Vol.05を読めばスッキリします。

  2. 「毎回手でやっている作業」を1つ思い浮かべ、そこに使っているツールのAPIで自動化できるか考えてみる
  3. Vol.05（MCPがあるツール一覧）に進んで、APIとMCPの違いを確認する
